# Abbreviations

The following is a table of abbreviations used in the repository, in addition to those specified in Barr Group's *Embedded C Coding Standard*. These only apply to the code that we wrote, and not the APIs we used.

| Abbreviation | Term        |
| ------------ | ----------- |
| `ms`         | millisecond |
| `us`         | microsecond |
| `ns`         | nanosecond  |
| `coord`      | coordinate  |
| `row`(`s`)   | row(s)      |
| `col`(`s`)   | column(s)   |
